nmap

Nmap (Network Mapper) is a powerful and versatile tool used for network discovery and security auditing.

Basic flags:

  • -sn Ping scan: This flag performs host discovery without scanning for open ports. It checks which hosts are up in the network.
  • -sS Stealth (SYN) scan: This is the default and most popular scan option because it is faster and stealthier than the default TCP connect scan. It only sends SYN packets and waits for responses.
  • -sT TCP connect scan: This is the default scan used when SYN scan isn't an option. It completes the three-way handshake and is easier to detect.
  • -sV Version detection: This flag allows Nmap to determine the version of the services running on open ports.
  • -O OS detection: This flag enables operating system detection, helping identify the OS of the target machine.
  • -A Aggressive scan: This flag enables OS detection, version detection, script scanning, and traceroute in one go.
  • -p Port specification: This flag allows you to specify which ports to scan. You can scan individual ports, ranges, or even all ports.
  • -Pn No ping: This flag treats all hosts as online, skipping host discovery.
  • -sU UDP scan: This flag is used to scan for open UDP ports on the target machine.
  • -sC Script scan: This flag enables the Nmap Scripting Engine (NSE) to run a set of scripts against the target.
  • -T Timing template: This flag sets the timing for the scan. Levels range from 0 (paranoid) to 5 (insane).
